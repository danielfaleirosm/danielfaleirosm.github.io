# danielfaleirosm.github.io

Trabalho de química.

**[Álcool, fenol e enol →](https://danielfaleirosm.github.io/)** — apresentação do
Seminário de Funções Orgânicas, Grupo 1.

Deck interativo com as três funções, 12 compostos reais com a estrutura química e o
grupo funcional em destaque, tautomeria ceto-enólica e um quiz. Funciona no
computador, na TV e no celular.

| tecla | ação |
| --- | --- |
| `→` `espaço` `roda` | avança |
| `←` | volta |
| `R` | roteiro do grupo |
| `T` | cronômetro |
| `F` | tela cheia |

A página é o `index.html` da raiz (há uma cópia em `docs/` para o caso de o Pages
estar publicando de lá — dá para apagar uma das duas depois de confirmar qual vale).
Arquivo único, sem dependências: as estruturas são SVG embutidos, gerados com RDKit
a partir dos SMILES do PubChem.
